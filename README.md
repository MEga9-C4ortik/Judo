# Judo Technique Library

An interactive reference library for judo techniques, built with React + Vite.
Created for the Sunway University Judo Club

## Features

- Browse techniques by category (Nage-waza / Ne-waza)
- Each technique includes Japanese name, kanji, description and video reference
- Video demos from the official Kodokan YouTube channel

## Tech Stack

- React 19
- Vite
- JavaScript

## Getting Started

git clone https://github.com/yourusername/yourrepo.git
cd yourrepo
npm install
npm run dev
